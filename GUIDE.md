# GUIDE.md — Простая инструкция для новичка

Этот сайт — набор обычных файлов. Чтобы что-то поменять, открой нужный файл в любом
текстовом редакторе (Блокнот, VS Code и т.п.), измени текст и сохрани. Всё!

Страницы сайта:
- `index.html` — главная страница
- `team.html` — страница «Команда»
- `servers.html` — страница «Серверы» (игры)
- `wall.html` — страница «Стена»

---

## 1. Где менять цвета сайта?

Открой файл **`css/base.css`**. В самом начале файла есть список цветов, например:

```
--bg-primary: #0a0a12;      /* цвет фона страницы */
--bg-card: #1a1a2e;          /* цвет карточек */
--neon-blue: #00d4ff;        /* голубой акцент */
--neon-purple: #7b2ff7;      /* фиолетовый акцент */
--neon-pink: #ff006e;        /* розовый акцент */
--text-primary: #e8e8f0;     /* основной цвет текста */
```

Цвета записаны в виде `#xxxxxx` — это код цвета. Поменяй буквы и цифры после `#`
на нужный код цвета. Коды любых цветов можно легко найти в интернете по запросу
«палитра цветов hex».

**Важно:** меняй только сам код цвета, а не название слева (например `--neon-blue`).
Тогда весь сайт сразу перекрасится, потому что все страницы берут цвета отсюда.

## 2. Как добавить нового человека в команду?

Открой файл **`team.html`**. Найди там блок одного человека — он начинается со строки:

```html
<div class="team-card founder">
```

Скопируй весь этот блок целиком (от `<div class="team-card...` до его закрывающего
`</div>`, обычно около 20 строк) и вставь его рядом — внутри блока `<div class="team-grid">`.

Потом в копии поменяй:
- имя человека (там, где он подписан крупно);
- должность (строка с `team-role`);
- описание (строка с `team-desc`);
- ссылки (строки с `team-link`).

Сохранить файл — человек появится на странице «Команда».

## 3. Как добавить новую игру на страницу серверов?

Открой файл **`servers.html`**. Каждая игра — это блок, который начинается со строки:

```html
<div class="server-card">
```

Скопируй любой такой блок целиком и вставь рядом (внутри блока `<div class="servers-grid">`).
В копии поменяй:
- название игры;
- текст описания;
- ссылку на Discord-сервер (атрибут `href="..."` у кнопки).

Сохранить файл — игра появится на странице «Серверы».

## 4. Где менять текст на главной странице?

Открой файл **`index.html`**. Весь видимый текст написан прямо в этом файле между
тегами. Ищи нужный кусок по самому тексту (можно нажать Ctrl+F и ввести фразу):

- большой заголовок сверху страницы;
- блоки «О нас» и карточки;
- текст внизу (футер).

Меняй только текст **между** тегами, например между `<p>` и `</p>`,
или между `<h1>` и `</h1>`. Сами теги (`<...>` и `</...>`) не удаляй.

## 5. Как добавить новую страницу?

Самый простой способ — скопировать существующую страницу:

1. Скопируй файл `index.html` и назови копию как хочешь, например `about-us.html`.
2. Открой новый файл и поменяй в нём текст на свой.
3. Вверху файла найди строчку `<title>...</title>` — это название вкладки браузера,
   поменяй его.
4. Чтобы ссылка на новую страницу появилась в верхнем меню на всех страницах,
   открой каждый файл (`index.html`, `team.html`, `servers.html`, `wall.html`),
   найди там меню (блок `<ul class="nav-links">`) и добавь в него такую строчку:

   ```html
   <li><a href="about-us.html">Название</a></li>
   ```

Готово! Открывай новую страницу в браузере двойным щелчком по файлу.

## Если что-то сломалось

Сайт перестал выглядеть нормально? Скорее всего, случайно удалился или испортится
какой-то тег. Верни изменённый файл как было (в Git можно отменить изменения файла)
и попробуй ещё раз, внимательнее копируя блоки целиком.
