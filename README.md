# NeoLand — сайт сообщества

Статический многостраничный сайт Discord-сообщества **NeoLand** (HTML + CSS + Vanilla JS, без сборки и зависимостей).

## Структура проекта (после реконструкции)

```
.
├── index.html          # Главная: hero, о сообществе, ресурсы, разделы сайта
├── team.html           # Команда (основатели)
├── wall.html           # Стена памяти и достижений + таймлайн истории
├── servers.html        # Игровые сервера (Project Zomboid, Barotrauma, Valheim)
├── css/
│   ├── base.css        # CSS-переменные, сброс стили, контейнер
│   ├── layout.css      # Навигация, hero, секции, футер
│   ├── components.css  # Кнопки и карточки (about, resources, team, wall, servers, timeline)
│   └── responsive.css  # Медиазапросы (адаптив ≤768px)
├── js/
│   ├── config.js       # Селекторы анимируемых карточек
│   ├── scroll-reveal.js# Плавное появление элементов при скролле (IntersectionObserver)
│   └── main.js         # Точка входа (ES-модуль)
├── style.css           # Shim обратной совместимости (@import всех модулей css/)
├── script.js           # Shim обратной совместимости (автономная копия js/)
└── LICENSE
```

## Что изменилось в ходе реконструкции

1. **Разделение стилей.** Монолитный `style.css` (~16 КБ) разбит на 4 логических модуля в `css/`; страницы подключают их напрямую. Старый `style.css` сохранён как shim через `@import`, чтобы внешние ссылки не сломались.
2. **Модульный JavaScript.** `script.js` переписан на ES-модули (`js/main.js` + `js/scroll-reveal.js` + `js/config.js`), подключается через `<script type="module">`. Добавлен `observer.unobserve()` — наблюдатель больше не отслеживает уже проявленные элементы.
3. **Семантика HTML.** Контент каждой страницы обёрнут в `<main>`; декоративные эмодзи-иконки помечены `aria-hidden="true"`; добавлены `preconnect`/`preload` для Google Fonts.
4. **Удалены инлайн-стили.** Градиенты аватаров и обложек серверов вынесены в CSS-модификаторы (`.av-neon`, `.av-pink`, `.bg-zomboid`, `.bg-baro`, `.bg-valheim`).
5. **Исправления контента и багов.**
   - В навигации `wall.html` и hero главной страницы отсутствовала молния «⚡» в пустых `<span class="bolt">` / `<span class="bolt-big">` — восстановлена.
   - Пустые иконки карточек на главной (`card-icon`, `nav-card-icon`) заполнены эмодзи (🚀, 🖥️).
   - Устранена опечатка «Подводная подводная лодка» и неточность «десятый мир» → «десять миров» (Valheim) на странице серверов.
   - Дублирующийся класс `section page-header` заменён на `page-header` (отступы задаёт сам класс).
   - Внешним ссылкам с `target="_blank"` добавлен `rel="noopener"`.

## Локальный запуск

Проект — чистая статика, достаточно любого локального сервера (важно для ES-модулей):

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Либо просто открыть `index.html` в браузере (для `type="module"` предпочтителен HTTP-сервер).
